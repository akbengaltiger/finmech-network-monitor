# Security Policy

## Reporting a Security Issue

Please do not publish credentials, internal network information, SNMP community strings, private infrastructure details, or exploitable security findings in a public GitHub issue.

For this portfolio repository, security-sensitive information should be reported privately to the repository owner.

## Sensitive Information Policy

This public repository must not contain:

- Production credentials or passwords
- API keys or tokens
- SNMP community strings
- Internal IP addresses or hostnames
- Database connection secrets
- Private topology or customer information
- Production logs containing sensitive data

Use placeholders and sanitized examples in all public documentation.

## Scope

This repository is a sanitized technical showcase of Finmech Network Monitor (FNM). Production infrastructure and organization-specific configuration are intentionally outside the public repository.
